mend is a dependency-free Node.js 22 CLI that applies unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits atomically. It supports whitespace-aware matching, safe paths, moves, and dry-run checks.

## Run it

```sh
node main.ts [options] [PATCH]
```
